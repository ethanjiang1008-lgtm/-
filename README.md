# 首板连板概率模型 · Local Edition

> A股首板/连板次日晋级概率评分模型，**纯本地运行、零算力依赖、免费数据源**。

当日收盘后跑一次 `python run_daily.py`，输出明日连板概率榜；用 `python backtest.py`（东财涨停池全因子）或 `python backtest_baostock.py`（baostock 全历史长周期）回测模型准确性。

## 功能

- **8 因子加权评分**（题材强度 / 市场情绪 / 个股身位 / 封板时间 / 封板质量 / 板块梯队 / 连板身位 / 资金验证），0–100 分
- **概率校准**：`基准晋级率 × (0.6 + 综合分/100)`，基准率按身位分档（首板16% / 2板33% / 3板48% / 4板50%），上限 85%
- **每日选股 + 可视化网页**：`python run_daily.py` → 打印全部涨停股评分 + Top 榜单，并**自动生成预测网页** `daily_prediction_YYYYMMDD.html`（统计卡 / Top10 概率榜 / 全部明细表 / ECharts 分布图），用浏览器打开即可查看当日预测结果
- **双源历史回测**：
  - `python backtest.py` —— AKShare 东财涨停池，**8 因子完整口径**（封板时间/炸板次数/封板资金齐全），但涨停池历史仅保留最近约 15 个交易日
  - `python backtest_baostock.py` —— baostock 全市场日线，**可回测任意长区间**（默认近 1 年），连板数/涨停判定本地自算；因数据源无封板时间等字段，因子为简化版（连板身位/市场情绪/个股身位/封板质量/题材中性）
- 数据源 [AKShare](https://akshare.akfamily.xyz/) + [baostock](http://baostock.com/)，均免费、无需 token、无需 GPU

## 环境要求

- Python 3.10+
- 安装依赖：`pip install -r requirements.txt`

## 快速开始

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 当日选股（默认取最近一个交易日；运行后自动生成预测网页）
python run_daily.py
# 指定日期
python run_daily.py --date 2026-09-18
# 只打印 Top 10 / 跳过网页 / 另存 CSV
python run_daily.py --top-n 10 --no-html --out daily_result.csv

# 3. 历史回测（东财全因子版，受涨停池近端限制）
python backtest.py --days 60 --top-n 5
# 首板专项（只在首板池内选股）
python backtest.py --days 60 --top-n 5 --first-board

# 4. 历史回测（baostock 长周期版，推荐用于准确性评估）
python backtest_baostock.py --start 2025-06-02 --end 2026-09-18 --top-n 5
# 首板专项
python backtest_baostock.py --start 2025-06-02 --end 2026-09-18 --top-n 5 --first-board
# 首次运行会拉取全市场日线（约 20-40 分钟），之后走本地缓存秒级完成
```

## 回测逻辑

```
逐交易日：
  1. 取当日涨停池（东财：含首封时间/连板数/题材/封板资金；baostock：本地自算涨停与连板）
  2. 按因子打分 → 输出概率 → 按概率取 Top N
  3. 「尾盘买入」= 以当日收盘价（涨停价）买入
  4. 次日判断：次日收盘价继续涨停 → 连板命中；否则记收益 = 次日收盘涨跌幅
统计：
  - 连板命中率（次日涨停占比）
  - 平均次日收益 / 胜率 / 盈亏比
  - 与全量涨停池基准（未筛选）对比
```

## 模型口径（可配置，见 config.py）

| 因子 | 权重 | 数据来源（涨停池字段） |
|---|---|---|
| 题材强度 | 20% | 所属行业当日涨停家数 |
| 市场情绪 | 15% | 全市场涨停家数/连板家数温度 |
| 个股身位 | 15% | 流通市值 / 换手率 / 成交额 |
| 封板时间 | 15% | 首次封板时间（越早分越高） |
| 封板质量 | 10% | 炸板次数（越少分越高） |
| 板块梯队 | 10% | 题材内最高连板身位 |
| 连板身位 | 10% | 当日连板数 |
| 资金验证 | 5% | 封板资金 / 成交额 |

## 回测验证结果（2025-06-02 ~ 2026-09-18，319 个交易日）

| 回测场景 | 样本 | 模型命中率 | 基准命中率 | 提升 | 模型均收 | 基准均收 |
|---|---|---|---|---|---|---|
| 全池 Top5（1年·简化因子） | 1595 笔 | **38.81%** | 20.79% | +18.0pp | +3.15% | +1.53% |
| 首板专项（1年·简化因子） | 1595 笔 | 14.67% | 14.09% | +0.6pp | +1.47% | +1.28% |
| 首板专项（15日·8因子完整版） | 67 笔 | **22.39%** | 15.81% | +6.6pp | +2.46% | +0.79% |

**关键发现**：
1. 模型在"全池"（首板+连板）有显著区分度：Top5 次日连板命中率 38.81%，为全池基准（20.79%）的 1.9 倍。
2. **Top1-5 名次命中率梯度清晰**（全池 · 1年，每日去重后按分数排序）：第1名 **42.63%** / 第2名 **42.95%** / 第3名 37.30% / 第4名 36.48% / 第5名 35.57% —— 前两名显著优于后三名。
3. 首板连板是低概率事件，自然晋级率约 **14%**（1 年 21772 笔首板实测）。
4. **8 因子完整版（封板时间/炸板/封板资金/题材）对首板选股有效**（22.39% vs 15.81%）；仅靠价格/身位的简化因子几乎无提升——封板质量类因子是首板选股的核心 alpha。
5. 连板身位越高晋级率越高（1 板 33% → 6 板 54%，模型 Top5 内分布）。
6. 月度波动大（26.7%~51.0%），情绪冰点月区分度下降，建议结合市场情绪做仓位管理。

完整可视化报告见 `first_board_model_report.html`。

## 已知限制

- 东财涨停池接口仅保留最近约 15 个交易日历史，全因子回测样本受限；长周期评估请用 baostock 版。
- baostock 版无封板时间/炸板次数/封板资金字段，用涨幅强度近似封板质量，属简化口径。
- 20cm（创业板/科创板）与 ST 涨停阈值已按规则区分（9.8/19.8/4.8）。
- 模型为经验量化框架，历史回测不代表未来收益。
