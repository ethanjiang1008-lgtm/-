# 首板连板概率模型 · Local Edition（v2）

> A股首板/连板次日晋级概率评分模型，**纯本地运行、零算力依赖、免费数据源**。

当日收盘后跑一次 `python run_daily.py`，输出明日连板概率榜（**每只股票附预测理由**）；用 `python backtest_baostock.py`（baostock 全历史长周期）回测模型准确性。

## 功能

- **v2 评分（10 因子）**：连板身位 25% / 涨停频率(近10日涨停次数) 15% / 5日动量 15% / 市场情绪 10% / 个股身位 10% / 封板质量 10% / 封板时间 8% / 板块梯队 7%（东财版）；baostock 版为简化六因子（身位30% / 涨停频率20% / 动量15% / 个股15% / 封板质量10% / 情绪10%）
- **首板专项模式**：`--first-board` 时涨停频率绝对主导（近10日涨停次数是首板晋级二板的最强因子，回测证实）
- **预测理由**：每只股票输出中文解释（身位/涨停频率/动量/封板/题材/市值等因子贡献）
- **概率校准**：`基准晋级率 × (0.6 + 综合分/100)`，基准率按身位分档（v2 回测实测：首板16% / 2板29% / 3板42% / 4板40% / 5板48% / 6板53%），上限 85%
- **每日选股 + 可视化网页**：`python run_daily.py` → 打印全部涨停股评分 + Top 榜单，并**自动生成预测网页** `daily_prediction_YYYYMMDD.html`（统计卡 / Top10 概率榜(含预测理由) / 全部明细表 / ECharts 分布图）
- **精准模式**：只做「当日最高分且连板身位≥6」的第一名（宁缺毋滥），全期命中率 50.0%
- **双源历史回测**：
  - `python backtest_baostock.py` —— baostock 全市场日线，**可回测任意长区间**（默认近 1 年），连板数/涨停判定本地自算
  - `python backtest.py` —— AKShare 东财涨停池，**10 因子完整口径**（封板时间/炸板次数/封板资金齐全），但涨停池历史仅保留最近约 15 个交易日
- 数据源 [AKShare](https://akshare.akfamily.xyz/) + [baostock](http://baostock.com/)，均免费、无需 token、无需 GPU

## 环境要求

- Python 3.10+
- 安装依赖：`pip install -r requirements.txt`

## 快速开始

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 当日选股（默认取最近一个交易日；自动生成预测网页，含每只股票预测理由）
python run_daily.py
# 指定日期
python run_daily.py --date 2026-09-18
# 只打印 Top 10 / 跳过网页 / 另存 CSV
python run_daily.py --top-n 10 --no-html --out daily_result.csv
# 首板专项（只预测首板晋级二板）
python run_daily.py --first-board

# 3. 历史回测（baostock 长周期版，推荐用于准确性评估）
python backtest_baostock.py --start 2025-06-02 --end 2026-09-18 --top-n 5
# 首板专项
python backtest_baostock.py --start 2025-06-02 --end 2026-09-18 --top-n 5 --first-board
# 精准模式：只做当日最高分且身位≥6 的第一名（命中率 50%）
python backtest_baostock.py --start 2025-06-02 --end 2026-09-18 --top-n 1 --min-boards 6
# 首次运行会拉取全市场日线（约 20-40 分钟），之后走本地缓存秒级完成

# 4. 历史回测（东财全因子版，受涨停池近端限制）
python backtest.py --days 60 --top-n 5
```

## 回测逻辑

```
逐交易日：
  1. 取当日涨停池（东财：含首封时间/连板数/题材/封板资金；baostock：本地自算涨停与连板）
  2. 按 v2 因子打分 → 输出概率 → 按概率取 Top N
  3. 「尾盘买入」= 以当日收盘价（涨停价）买入
  4. 次日判断：次日收盘价继续涨停 → 连板命中；否则记收益 = 次日收盘涨跌幅
统计：
  - 连板命中率（次日涨停占比）
  - 平均次日收益 / 胜率 / 盈亏比
  - 与全量涨停池基准（未筛选）对比
```

## 模型口径（v2，可配置见 config.py）

| 因子 | 权重 | 数据来源 | 说明（回测依据） |
|---|---|---|---|
| 连板身位 | 25% | 当日连板数 | 身位差距已拉开：6板+ 10 / 5板 9 / 4板 8 / 3板 7 / 2板 6 / 1板 5 |
| 涨停频率 | 15% | 近10日涨停次数 | **首板晋级二板最强因子**：lim10≥5 → 命中率 31.2% vs 基准 16.4% |
| 5日动量 | 15% | 5日涨幅 | 动量≥50% → 32.8% vs <10% → 17.2% |
| 市场情绪 | 10% | 全市场涨停家数 | 涨停<40家 30.5% vs ≥100家 19.0%（过热日反而难连板） |
| 个股身位 | 10% | 流通市值 | 小盘弹性 |
| 封板质量 | 10% | 炸板次数 | 越少分越高 |
| 封板时间 | 8% | 首次封板时间 | 越早分越高 |
| 板块梯队 | 7% | 题材内最高连板 | 梯队前排 |

## 回测验证结果 v2（2025-06-02 ~ 2026-09-18，319 个交易日，尾盘买入/次日连板口径）

| 回测场景 | 样本 | 模型命中率 | 基准命中率 | 提升 | 模型均收 | 胜率 |
|---|---|---|---|---|---|---|
| 全池 Top1 + 身位≥6（精准模式） | 140 笔 | **50.00%** | 21.65% | +28.4pp | +4.03% | 67.1% |
| 全池 Top5（v2 六因子） | 1595 笔 | **40.31%** | 20.79% | +19.5pp | +2.83% | 64.9% |
| 首板专项 Top1（涨停频率主导） | 319 笔 | **25.08%** | 16.36% | +8.7pp | +0.78% | 57.4% |
| 首板专项 Top5（涨停频率主导） | 1594 笔 | **23.40%** | 16.36% | +7.0pp | +1.14% | 58.2% |

**v1 → v2 提升**：

| 场景 | v1 | v2 | 提升 |
|---|---|---|---|
| 全池 Top1 | 42.63% | **50.00%**（+身位≥6 精准模式） | +7.4pp |
| 全池 Top5 | 38.81% | **40.31%** | +1.5pp |
| 首板专项 Top1 | 15.67% | **25.08%** | +9.4pp |
| 首板专项 Top5 | 14.67% | **23.40%** | +8.7pp |

**分段稳健性（前 2/3 训练 2025-06~2026-02 / 后 1/3 验证 2026-03~2026-09）**：

| 场景 | 全期 | 训练段 | 验证段 |
|---|---|---|---|
| 全池 Top1 + 身位≥6 | 50.0%（140） | 51.2%（86） | 48.2%（54） |
| 全池 Top5 | 40.3%（1595） | 42.1%（900） | 38.0%（695） |
| 首板 Top1 | 25.1%（319） | 27.2%（180） | 22.3%（139） |
| 首板 Top5 | 23.4%（1594） | 25.0%（900） | 21.3%（695） |

**关键发现（v2 因子探索，2025-06~2026-09 全市场 29464 个涨停样本）**：
1. **连板身位是王者因子**：1板 16.4% → 2板 29.6% → 3板 43.1% → 4-5板 43.4% → 6板+ 51.95%（自然晋级率，未筛选）。
2. **近10日涨停次数是首板最强因子**：lim10≥5 时首板命中率 31.2%（n=311），lim10 3-4次 22.8%，0-1次 15.5%。
3. **5日动量区分度强**：全池动量≥50% 32.8% vs <10% 17.2%；但首板池内动量区分度弱（不参与首板主导排序）。
4. **市场情绪过热反而难连板**：涨停≥100家 19.0% vs <40家 30.5%（冰点涨停更实在）。
5. **验证段（2026-03 以来）市场环境明显变差**：所有策略验证段命中率低于训练段 3-5pp，这是市场环境（非模型缺陷），任何单票次日连板预测都无法保证任意时段 ≥50%。
6. **50% 的代价**：全池 TOP1+身位≥6 只出手 140/319 天（44%），即高命中率需要接受约一半交易日空仓。

完整可视化报告见 `first_board_model_report.html`。

## 已知限制

- 东财涨停池接口仅保留最近约 15 个交易日历史，全因子回测样本受限；长周期评估请用 baostock 版。
- baostock 版无封板时间/炸板次数/封板资金字段，用涨幅强度近似封板质量，属简化口径。
- 20cm（创业板/科创板）与 ST 涨停阈值已按规则区分（9.8/19.8/4.8）。
- 单票次日连板预测受市场环境影响大，验证段（2026-03 以来）所有策略命中率下降 3-5pp；首板晋级二板天然是低概率事件（物理上限约 28-31%），50% 目标对首板不可达，请以"超额 vs 基准"评估模型价值。
- 模型为经验量化框架，历史回测不代表未来收益。
