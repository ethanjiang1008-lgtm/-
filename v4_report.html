一、核心结论

  • 低位池（1-3 板）最优策略：只保留「放量倍数 < 6」的 1-3 板涨停股（排除天量分歧票），按「同身位桶内成交额分位」校准概率取 TOP → TOP1 命中率 65.7%（v3 同口径 52.5%，提升 +13.2pp）。
  • 首板池专项：只保留「首板且换手率 < 3%」的惜售锁筹票 → TOP1 31.6%（v3 同口径 21.5%，提升 +10.1pp）。
  • 验证段命中率不弱于训练段（低位池 68.3% → 63.8%，首板 33.3% → 30.4%），非过拟合。
  • 多因子等权组合会互相稀释强信号；「收敛到最强 1-2 个因子 + 规则过滤」远优于「六因子加权」。这是 v4 相对 v3 的核心改进。

五、v4 每日选出的票长什么样

  • 身位分布：TOP1 全为 2-3 板（242 日中 2 板 130 日 / 3 板 112 日，无 1 板）。
  • 换手分布：< 2% 占 46.7%、< 5% 占 82.6%、≥ 15% 仅 2.9% —— 低换手惜售是绝对主导。
  • 画像：「大成交额 + 缩量/低换手的 2-3 板票」，即市场资金关注且筹码锁定充分的连板中位股。

六、数据与方法

  • 数据源：baostock 日线 1,839,023 行（2025-06-03 ~ 2026-09-21，主板 3,153 只，含换手/成交额/成交量）。
  • 样本构建：主板（60/00 开头、非 ST）当日 pct ≥ 9.8% = 涨停；次日仍涨停 = 连板命中；构建 14,924 条 / 242 交易日，训练（前 5,814 条）与验证（后 9,110 条）按 2026-03-01 切分。
  • 校准法：身位桶（1/2/3/4+）× 因子分位（Q1-Q5）→ 训练段实测晋级率；验证段独立评估；每日排序按概率降序，同分固定种子随机破平局，位次命中率按每日第 N 名样本统计。
  • 复现：python build_samples.py && python exp_iter2.py && python exp_iter3.py && python exp_iter4_final.py && python make_calib_v4.py
局限：① 首板基础晋级率仅 16%，首板 50%+ 需叠加当日盘口因子（封板时间/封单金额/炸板），东财涨停池历史仅存约 2 周、无法一年回测，已作为下一阶段方向；② 消息面（如新华传媒重组预期）无法量化进历史回测，模型输出理由仅基于量能/盘面统计。免责声明：本报告不构成投资建议。
